Notes for coding agents (Claude, Codex) working in this repo.

## Blockers go on the Message Board

Blueprints keeps one Message Board for every repo in the org:
https://github.com/blueprints4pangaea/endgame/issues/13

When work is blocked on something code can't fix, post it there as a comment, not only in a PR, a chat or local notes. That covers an API key, a service account, access to a sheet or an account, or a deploy that only someone else can run. Say what's blocked, what's needed, and who can do it. Never paste secrets or key values.
